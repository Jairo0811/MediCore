# Dominicana Icons — MediCore

MediCore incluye iconografía dominicana como identidad visual contextual del proyecto.

## Política de uso

- Los iconos dominicanos no sustituyen iconos funcionales de la interfaz clínica.
- Acciones como autenticación, navegación, pacientes, farmacia, laboratorio, inventario y auditoría conservan su iconografía UI estándar.
- Los SVG decorativos deben marcarse con `aria-hidden="true"` y texto accesible cuando el contexto lo requiera.
- Los assets se sirven desde `src/MediCore.Web/public/icons/dominicana/`.

## Integración inicial

`mapa-rd.svg` identifica de forma secundaria el origen dominicano del proyecto mediante el marcador “Proyecto desarrollado en República Dominicana”.

Esta integración es un patch visual posterior al cierre y no modifica reglas de negocio ni funcionalidades clínicas.
